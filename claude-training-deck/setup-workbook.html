Claude Setup Workbook

Follow these 5 steps during the workshop. By the end, you'll have a working Claude setup.

Estimated time: 45 minutes · You'll need: Claude desktop app (installed) · Pro account

Step 1 · 5 minutes

Create Your Project Folder

Claude works best when it has its own folder. This is where it reads your context files and saves its work.

1. Open Finder (or File Explorer)

2. Go to your Desktop or Documents

3. Create a new folder called claude-projects

4. Inside it, create these subfolders:

   _context/ — your about-me, rules, company info

   _outputs/ — where Claude saves its work

   _templates/ — reusable prompt templates

Tip: The underscore (_) keeps these folders at the top of your file list. You'll thank yourself later.

Step 2 · 15 minutes

Write about-me.md — Your Personal Briefing

This is the most important file you'll create. It tells Claude who you are, how you work, and what you value. Every prompt you write will be better because of this file.

The fastest way to create it: let Claude interview you.

1. Open Cowork Mode

Desktop app → Top menu → Cowork → Select your claude-projects folder

2. Copy and paste this prompt exactly:

I want to create an about-me.md file in my _context/ folder.

Ask me questions one at a time (use AskUserQuestion).

I'll answer each one before you ask the next.

Cover these topics:

- What I do (role, industry, experience)

- How I like to work (communication style, preferences)

- What good looks like to me (quality standards)

- What I hate (pet peeves, things that waste my time)

- My goals (what I'm trying to accomplish)

After about 8 questions, compile everything into

a concise about-me.md file and save it.

Keep it under 2,000 tokens — tight and specific.

3. Answer Claude's questions

Claude will ask you ~8 questions, one at a time. Just answer naturally. Don't overthink it.

4. Check the result

Claude saves about-me.md in your _context/ folder. Open it and make any edits you want.

Tip: Keep this file under 2,000 tokens. Ruben Hassid (who wrote the guide we're following) trimmed his from 22,000 words down to under 2,000. The secret: extract the patterns, throw away the raw transcripts.

Step 3 · 10 minutes

Write anti-ai-writing-style.md — The "Don't Sound Like AI" File

Without this file, Claude writes in its default voice — which sounds exactly like every other AI output. This file tells it what not to do.

1. In the same Cowork session (or a new one), paste:

I want to create an anti-ai-writing-style.md file

in my _context/ folder.

Ask me questions one at a time (use AskUserQuestion).

Cover:

- What words and phrases do I hate? (e.g., "delve," "leverage," "game-changer")

- What patterns feel obviously "AI-written"?

- How long should sentences and paragraphs be?

- Should we use emojis? Exclamation marks?

- What tone is right for my team?

After about 6 questions, compile everything

into a tight anti-ai-writing-style.md and save it.

2. Be honest about what annoys you

This file only helps if it reflects what you actually hate. If "circle back" makes you cringe, put it in the banned list.

Tip: Ruben's version bans 80+ AI words like "delve," "harness," "tapestry," and kills "reframe patterns" (e.g., "this isn't X, this is Y"). Without this file, Claude writes like Claude. With it, Claude writes like you.

Step 4 · 10 minutes

Set Up CLAUDE.md — Your Project's Permanent Briefing

CLAUDE.md is a special file. Claude reads it automatically every time it starts working in your project folder. It's like "global instructions" for your project.

1. Create CLAUDE.md in the root of your claude-projects folder

(Not inside _context/ — right in claude-projects/)

2. Start with this template:

# CLAUDE.md

## Project

[What is this project for? One sentence.]

## Context Files

Before every task, read these files in _context/:

- about-me.md — who I am and how I work

- anti-ai-writing-style.md — tone and banned words

## Key Conventions

- [Rule 1: e.g., Save all outputs to _outputs/]

- [Rule 2: e.g., Use markdown format unless told otherwise]

- [Rule 3: e.g., Ask if something is unclear]

## Outputs

Save deliverables to _outputs/ in a subfolder

named by project or date.

3. Ask Claude to improve it

Prompt: "Read my CLAUDE.md and suggest 3 things I should add. Use AskUserQuestion to learn about my workflow."

Tip: CLAUDE.md is what transforms Claude from a chatbot into a teammate who remembers context. It's the single highest-leverage file you can create.

Step 5 · 10 minutes

Test Your Setup — First Real Task

Now let's see if everything works. Run a real task to confirm Claude reads your context files and produces useful output.

1. Open a new Cowork session on your claude-projects folder

2. Run this test prompt:

Read my CLAUDE.md, about-me.md, and anti-ai-writing-style.md.

Then draft a weekly status update for my team.

Save it as _outputs/test-output.md.

Before you write, use AskUserQuestion to ask me:

1. What did I accomplish this week?

2. What am I working on next?

3. Any blockers?

3. Check the result

Open _outputs/test-output.md. Does it sound like you? Does it follow your writing rules? If yes — your setup is complete!

Your Setup Cheatsheet

After completing all 5 steps, your folder should look like this:

claude-projects/

├── CLAUDE.md <-- Read automatically by Claude

├── _context/

│ ├── about-me.md

│ └── anti-ai-writing-style.md

├── _outputs/ <-- Claude saves work here

│ └── test-output.md

└── _templates/ <-- Reusable prompt structures

You're done when: You open Cowork, point it at claude-projects, run a prompt, and Claude produces output that sounds like you — without you having to explain who you are or how you work.

Quick Reference: The Cowork Template

Use this template for any task after your setup is complete:

Read my context files.

I want to [YOUR TASK] so that [WHAT SUCCESS LOOKS LIKE].

Don't start yet. First, ask me clarifying questions

(use AskUserQuestion) so we refine the approach together.

Only begin work once we've aligned.

What To Do In Your First Week

  • Day 1: Use the template above for one real task
  • Day 2: Add 2 banned words to anti-ai-writing-style.md
  • Day 3: Try "Read my _outputs/[file] and suggest improvements"
  • Day 4: Ask Claude to create a template for a recurring task
  • Day 5: Review and refine your about-me.md

Remember: Claude is the worst it has ever been right now — meaning it will only get better. Every file you create today compounds in value as the technology improves.
