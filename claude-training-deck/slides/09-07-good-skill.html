What Makes a Good Skill?

Characteristics

  • Specific scope
    One task, done well. "Summarize a meeting" not "help me with everything."
  • Clear inputs
    What does Claude need from the user? Transcript, URL, description?
  • Structured output
    The format is defined so every run produces consistent results.
  • Self-verification
    Ask Claude to check its own work for common errors.
  • Low maintenance
    A good skill doesn't need updating every week. Stable tasks make good skills.

Bad skill candidates

  • ✗ "Write anything I ask"
    Too broad — that's just Chat mode
  • ✗ "Refactor my entire codebase"
    Too variable — every run is different
  • ✗ "Analyze market trends"
    Needs current data — skills lack real-time access
  • ✗ "Do everything but better"
    Not a real task description

The test: Can you describe what the skill does in 10 words or fewer? If not, the scope is too broad.
