Anatomy of a Skill

A skill packages a prompt into a reusable /command. It lives in ~/.claude/skills/ and can be invoked by anyone on your team.

meeting-recap/

├── SKILL.md ← The instruction file

├── assets/ ← Optional images, templates

└── scripts/ ← Optional automation scripts

# SKILL.md

---

name: meeting-recap

description: Generate structured meeting summaries from transcripts

# Skill instructions

When invoked, I will:

1. Ask for the meeting transcript

2. Extract: decisions, action items, open questions

3. Output in a structured format

4. Flag unclear items

Skill benefits

  • One-word invocation
    Type /meeting-recap instead of re-writing the prompt
  • Team sharing
    Everyone on your team uses the same workflow
  • Consistent output
    Same format every time, no variations
  • Version control
    Skills live in files — track changes in git
  • Composability
    Skills can reference other skills
