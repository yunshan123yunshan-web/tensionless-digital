When to Cowork

Cowork mode is your pair programmer. Claude works alongside you with full file system access.

  • Coding — "Build this feature, write tests, refactor that module"
  • File operations — "Read this log, find the error, suggest a fix"
  • Project work — "Set up a new project with this structure"
  • Research & implement — "Find how other projects handle this, then implement it"

Cowork is best when:

• You need to read, write, or edit files
• The task has multiple steps with dependencies
• You want Claude to run commands and see output
• You're working in an existing project

Setup tip: Create a dedicated folder for each cowork session. Use CLAUDE.md for project-level instructions. Keep context files in a _context/ folder.
