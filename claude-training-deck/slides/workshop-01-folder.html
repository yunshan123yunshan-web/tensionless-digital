Workshop: Create Your Project Folder

Follow these steps. You'll have your folder set up in under 5 minutes.

Step 1

Open Finder → go to your Desktop

Step 2

Create a folder called claude-projects

Step 3

Inside it, create three subfolders:

_context/   _outputs/   _templates/

Step 4

Open Claude desktop → Cowork → Select your folder

Step 5

Run this to confirm it works:

"What files are in my project folder?"

Folder structure you'll have:

claude-projects/
├── _context/
├── _outputs/
└── _templates/

Pro tip: The underscore keeps context/outputs/templates at the top of your file list.
