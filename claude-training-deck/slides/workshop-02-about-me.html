Workshop: Write about-me.md

This is the most important file you'll create. The fastest way: let Claude interview you.

Copy this prompt into Cowork:

I want to create an about-me.md file in my _context/ folder.

Ask me questions one at a time (use AskUserQuestion).

I'll answer each before you ask the next.

Cover these topics:

- What I do (role, industry, experience)

- How I work (communication style, preferences)

- What good looks like (quality standards)

- What I hate (pet peeves, time-wasters)

- My goals (what I'm trying to accomplish)

After ~8 questions, compile everything into

a concise about-me.md and save it to _context/.

Keep it under 2,000 tokens — tight and specific.

How it works:

1. Paste the prompt → Claude asks Q1
2. Type your answer → Claude asks Q2
3. Repeat for ~8 questions
4. Claude compiles and saves about-me.md
5. Open the file → make any edits

Key insight: Ruben Hassid trimmed his from 22,000 words to under 2,000. Extract patterns, throw away raw transcripts.
