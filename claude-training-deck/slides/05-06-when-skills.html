When to Use Skills

Skills are your automated workflows. Package a task into a /command that anyone can run reliably.

  • Recurring tasks — "Write this up as a skill so I can run it weekly"
  • Team workflows — "Create a skill for PR reviews that everyone can use"
  • Standardized processes — "Meeting recap with consistent format every time"
  • Quality control — "Code review checklist that enforces our standards"

Skills are best when:

• You do the same task more than twice
• The task has a clear, repeatable structure
• Other team members need to run it too
• Consistency matters more than customization

Analogy: Chat is a conversation. Cowork is a workshop. Skills are a vending machine — put in a request, get a consistent result.
