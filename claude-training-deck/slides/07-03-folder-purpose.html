What Each Folder Does

Each directory in your project tells Claude something about how to work.

Folder / FilePurposeWhat Claude learns
CLAUDE.md Project-level instructions for Claude Goals, conventions, rules, architecture
src/ Source code Language, framework, code style, patterns
docs/ Architecture, API docs, guides Design decisions, rationale, context
tests/ Test suites Testing patterns, coverage expectations
scripts/ Build, deploy, utility scripts DevOps workflow, automation patterns
config files package.json, tsconfig, etc. Dependencies, tooling, project metadata

Key insight: You don't need a perfect structure to start. Even a CLAUDE.md and one src/ folder gives Claude 80% of what it needs.
