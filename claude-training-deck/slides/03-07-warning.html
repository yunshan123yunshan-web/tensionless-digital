An Important Warning

Better prompting with a weaker model almost always beatsweak prompting with a stronger model.

Don't:"Write a strategy doc" → Opus
— No context, no direction, expensive waste

Do:Full context + examples → Sonnet
— Better result at ⅓ the cost of Opus

The real hierarchy:

Great prompt + Sonnet > Mediocre prompt + Opus > Bad prompt + anything

Invest in your prompting skills first. The model is a multiplier, not a substitute.
