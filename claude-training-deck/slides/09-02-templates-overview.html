Three Types of Templates

Templates range from simple copy-paste prompts to full /command skills. Start simple, level up as you go.

Level 1: Prompt Templates

Reusable text prompts you copy and paste. Store in a doc or note. Best for: individual use, quick tasks, exploring a pattern.

Example: "Summarize this article in 3 bullet points"

📁

Level 2: Prompt Files

Markdown files in your project (e.g., .claude/prompts/). Claude can read them via Cowork mode. Best for: shared team patterns, documented workflows.

Example: .claude/prompts/meeting-recap.md

•

Level 3: Skills

Fully packaged /commands with SLK.md + optional scripts. Invoke with /skill-name. Best for: frequent tasks, team-wide distribution, complex workflows.

Example: /meeting-recap generates structured summaries

Rule of thumb: If you've done the same task with Claude 3 times, turn it into a template. If you'd do it weekly, turn it into a skill.
