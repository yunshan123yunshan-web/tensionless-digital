Rule 4: Specify Output Format

Tell Claude exactly how to structure the response. This saves you reformatting time and ensures the output is immediately usable.

✕ "Give me a list of ideas"

✓ "Output as a table with columns: Idea | Effort (Low/Med/High) | Impact (1-5) | Notes

Example:

| Idea | Effort | Impact | Notes |

|------|--------|--------|-------|

| X | Low | 4 | Quick win |

Common format specs:

  • Markdown / plain text / JSON
  • Table with specific columns
  • Bullet list vs numbered steps
  • Headline + subheadings + body
  • CSV for spreadsheet import

Rule of thumb: If you can describe the output structure, Claude can follow it. Be as specific as if you were telling a human assistant exactly how you want the document laid out.
