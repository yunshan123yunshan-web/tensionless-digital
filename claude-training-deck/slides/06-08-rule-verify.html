Rule 5: Ask Claude to Verify

Claude can check its own work — if you ask it to. Verification prompts catch mistakes before you do.

✕ "Write a SQL query to find duplicate users."

✓ "Write a SQL query to find duplicate users. Before responding, check: does this handle NULL emails? Does it exclude test accounts? Is it indexed efficiently?"

Verification prompts:

  • "Check your work for errors"
  • "List any assumptions you made"
  • "Rate your confidence 1-10"
  • "What edge cases did you consider?"

Always verify anything that matters. Claude is fluent and confident — even when wrong. Treat outputs as a first draft from a capable but imperfect teammate.
