05 / 10 · Chat vs Cowork vs Skills

Exercise: Choose the Mode

Match each task to the right mode: Chat, Cowork, or Skill.

"I need to refactor a large JavaScript file into smaller modules."

→ Cowork — needs file system access and multiple file operations

"I want to understand the pros and cons of different database options."

→ Chat — exploratory conversation, no files needed

"Every Monday I need a project status summary in a specific format."

→ Skill — recurring task with consistent format

"I need to debug why my deployment pipeline is failing."

→ Cowork — needs to read logs, run commands, test fixes
