The Context Window

The context window is the model's working memory — everything it can see at once. It includes your instructions, conversation history, uploaded documents, and the model's own output so far.

Key Insight

The context window is not a "memory" in the human sense. It's more like a whiteboard — everything written on it is visible to the model at once, but nothing persists between conversations unless you put it there.

Analogy: Working with Claude is like handing someone a research brief and a stack of reference materials on a desk. They can see everything you put there — but when you leave the room, the desk is cleared.
