Understanding the Sandbox

Claude in Cowork mode runs in a sandboxed environment — it can read and write files, but within boundaries you define.

🛡️

Safe Mode

Claude asks for permission before any file write. Best for exploration and review.

📁

Scoped Access

Claude can write to specific directories you define. Good for active development.

•

Full Access

Claude reads and writes freely within the project. Full trust, full speed.

Rule of thumb: Start in safe mode. Move to scoped when you trust the patterns. Full access is for experienced users who've built good CLAUDE.md guardrails.
