Project Summary Template

A prompt that turns project notes and status updates into a clean executive summary.

Project Summary

---

Role: You are a project management consultant reviewing a project's current state.

Task: Given the following project notes, produce a one-page summary with:

1. Status — On track / At risk / Blocked (with reason)

2. Completed — What was delivered this period

3. Next up — Priority items for next period

4. Risks — Anything that needs attention

5. Needs decision — Specific questions for stakeholders

Format: Use clear section headers. Bold key numbers. No fluff. Aim for 5-8 bullet points total.

Verify: Distinguish between completed work and work in progress. Flag any dates mentioned and check for scheduling conflicts.

---

[Paste project notes]

When to use:

  • Weekly status reports
  • Sprint reviews
  • Client check-ins
  • Project handoffs

Variation: Add "Read my-company.md for positioning context" before the task for client-facing summaries. The output will naturally align with your brand voice.
