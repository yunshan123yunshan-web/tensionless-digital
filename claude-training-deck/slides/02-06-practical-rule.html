The Restart Rule

When you feel the conversation getting long or the model starting to lose track of details:

Rule of thumb: If your chat has more than ~50 messages or is getting repetitive, start a fresh one.

Before you start fresh, ask Claude to write a handoff summary — a condensed version of what's been decided, what's pending, and any key context the new chat needs.

When to restart:

Conversation feels sluggish?

Restart. Long context slows processing.

Model repeats itself?

It's likely losing early context. Fresh start.

Topic has shifted?

Don't pile topics in one chat. New topic = new chat.

Need to preserve progress?

Ask for a handoff doc first, then restart fresh.
