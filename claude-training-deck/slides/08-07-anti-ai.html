# Anti-AI — Do Not

✕ Clichés to avoid:

- "Game-changer," "best-in-class," "cutting-edge"

- "Unlock potential," "drive innovation," "leverage technology"

- "In today's digital landscape" or "In today's fast-paced world"

✕ Bad habits:

- Don't open emails with "I hope this email finds you well"

- Don't use emojis in professional communication

- Don't add "friendly" or "just" before verbs

- Don't end every paragraph with an exclamation mark!

Why you need this

  • Claude defaults to corporate-friendly language — which often sounds like "AI wrote this"
  • Without anti-AI rules, every output needs manual editing to remove AI-isms
  • This file is the difference between "obviously AI" and "sounds like us"

Best practice: Add to this file every time Claude generates something that feels "off." Over 2-3 weeks, you'll build a comprehensive list.
