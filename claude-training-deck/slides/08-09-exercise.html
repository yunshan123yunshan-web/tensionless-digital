Exercise: Write Your Context Files

You'll create three context files for a fictional (or real) business.

File 1: about-me.md

Write 5-10 lines about yourself: role, experience, goals, communication preferences. Be honest — Claude will adapt to what you write.

File 2: writing-style.md

Define your tone in 3 words. List 3 words/phrases to avoid. Add 3 formatting rules. If you have examples of writing you love, include them.

File 3: anti-ai.md

List 5 "AI-sounding" phrases you want Claude to never use. Think about what bothers you in AI-generated content.

Test it

Ask Claude to draft an email using your files: "Read writing-style.md and anti-ai.md, then draft a brief email introducing our services to a potential client."

Compare: Try the same prompt without your context files. The difference is the value of context.
