When to Chat

Chat mode is your thinking partner. Use it when you need a conversation, not a file edit.

  • Exploring ideas — "What are the approaches to X?"
  • Learning — "Explain how this works, like I'm new to it"
  • Drafting — "Help me outline a proposal"
  • Analysis — "What do you think of this approach?"

Chat is best when:

• You don't know what you need yet
• The task is conversational, not operational
• Speed matters more than file access
• You're in early exploration mode

Chat has no file system access. If your task involves reading or writing files, switch to Cowork.
