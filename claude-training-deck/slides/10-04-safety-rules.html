Safety: What NOT to Do

Never trust Claude with:

  • Production database operations
    Always review generated SQL before running
  • Security-critical code
    Authentication, encryption, access control
  • Financial calculations
    Invoicing, tax, payroll — verify every number
  • Legal agreements
    Drafts are starting points, not final documents

Safety habits to build:

  • Review before running
    Read generated code/commands before executing
  • Use sandbox first
    Test in a safe environment before production
  • Never share secrets
    Don't paste API keys, passwords, or personal data
  • Verify factual claims
    Cross-check important statements

Bottom line:Claude is a tool, not a replacement for judgment. You are responsible for everything you ship.
