Drafting a Skill

Creating a skill is a four-step process. Start from a template you already use.

01

Find a repeatable task

Look at your prompt history. What do you ask Claude to do more than once a week? Meeting recaps, email drafts, code reviews — these are skill candidates.

02

Extract the template

Take your best prompt for that task and remove the specific content. What remains is the reusable structure — role, context, task, format, verification.

03

Package it

Create a folder in ~/.claude/skills/your-skill-name/. Write the instructions in SKILL.md with clear name, description, and step-by-step guidance.

04

Test and iterate

Run the skill 3 times with different inputs. Refine the instructions based on what doesn't work. Share with a teammate for feedback.

Quick start:

Ask Claude to help you create a skill. Say: "I want to create a skill for [task]. Help me write the SKILL.md file."

Claude will guide you through the structure and generate the file.

File structure:

~/.claude/skills/meeting-recap/
  ├── SKILL.md
  ├── assets/
  └── scripts/

Skills can be collaborated on in shared drives or git repos.
