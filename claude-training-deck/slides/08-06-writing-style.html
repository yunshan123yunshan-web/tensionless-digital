# Writing Style

Tone: Direct, confident, minimal jargon. Sound like a human, not a textbook.

Rules:

- Use contractions (we're, it's, don't)

- Lead with the conclusion, then context

- Short paragraphs (max 3 sentences)

- Avoid: leverage, utilize, paradigm, ecosystem

- Use "you" and "we" — conversational but professional

Formatting:

- Headers: sentence case, not Title Case

- Bullets for lists of 3+ items

- Bold for key terms, not emphasis
