Verification Patterns

Add these verification prompts to the end of any important request.

ScenarioVerification prompt
Code "Review this code for bugs, security issues, and performance problems. List each issue with severity."
Writing "Check for unclear phrasing, jargon, overly complex sentences, and tone inconsistencies."
Data analysis "List all assumptions you made. Flag any edge cases not covered. Rate your confidence 1-10."
Strategy "What alternatives did you consider? Why did you recommend this one? What would change your recommendation?"
Design "What trade-offs does this design make? What user needs might it not address? How would it scale?"
Facts "Mark every factual claim with your confidence level. Distinguish between established facts and reasonable inferences."

Habit: End every important prompt with "Check your work." Two words that catch most mistakes.
