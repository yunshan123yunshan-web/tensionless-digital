05 / 10 · Chat vs Cowork vs Skills

Mode Selection Guide

You want to…ModeWhy
Brainstorm ideas, ask "what if" questionsChatNo setup, pure dialogue, fast iteration
Write or edit code in a projectCoworkFile access, command execution, context awareness
Create a reusable workflow for your teamSkillsPackage prompts + instructions into a /command
Get a quick explanation of a conceptChatFast, focused, no context overhead
Refactor a large codebaseCoworkNeeds file system, git, and full project context
Standardize a recurring processSkillsConsistent execution, shared across team
Draft and iterate on a documentChatConversational refinement works well here

Rule of thumb: Start in Chat to explore. Move to Cowork when you need to touch files. Graduate to Skills when you do it more than twice.
