What to Add to Your Rules

Your CLAUDE.md should include safety guardrails. Here's what the best ones contain.

# Safety Rules

## Never do without explicit approval:

- Modify production data (databases, live configs)

- Delete files or folders

- Run commands with sudo or elevated privileges

- Make irreversible changes without a rollback plan

## Always verify:

- SQL queries before execution

- Deployment commands before running

- Financial calculations before sharing

- Code with security implications

## Data privacy:

- Never paste production credentials

- Mask sensitive data in logs and examples

- Use environment variables for secrets

Why this matters:

  • Claude follows your rules — so the rules need to be right
  • Safety rules in CLAUDE.md are always loaded
  • They protect you when you forget to add a safety reminder
  • They also protect new team members learning the workflow
