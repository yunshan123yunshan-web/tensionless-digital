Tokens: The Currency of Thought

LLMs don't read words — they read tokens. A token is ~4 characters or ~¾ of a word in English.

"Claude is an AI assistant created by Anthropic"

Claude is an AI assistant created by Anthropic

→ 14 tokens · ~10 words

Why this matters: tokens = money. Every API call, every prompt, every output — all priced per token. And context windows are measured in tokens.
