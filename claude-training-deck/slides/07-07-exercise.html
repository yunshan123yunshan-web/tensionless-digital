Exercise: Set Up a Cowork Project

Pick a real project (or create a test one) and set it up for Cowork mode.

Step 1: Create a CLAUDE.md

Write a short CLAUDE.md with: project purpose, tech stack, conventions, and architecture notes. Keep it under 50 lines.

Step 2: Organize the structure

Make sure your project has at least: a src/ folder, a docs/ or README.md, and a config file (package.json, tsconfig, etc.).

Step 3: Run your first task

Open Cowork mode in that directory. Ask Claude to "Read the project structure and describe what this project does."

Step 4: Write a simple function

Ask Claude to add a small utility function. Review the output. Does it follow your conventions? Iterate if needed.

Goal: By the end, you should feel comfortable opening a project and giving Claude a task. The goal is trust, not perfection.
