Which Model for Which Task?

TaskRecommended ModelWhy
Sort a CSV, classify emails, extract data Haiku Simple, structured, high volume — no deep reasoning needed
Write a blog post, build a feature, debug code Sonnet Requires understanding + generation, but well-scoped
Design system architecture, review security Opus Needs broad context, trade-off analysis, and deep reasoning
Real-time chatbot, customer support Haiku Latency-critical, predictable patterns
Complex data analysis, research synthesis Sonnet Multi-step with intermediate results
Content strategy, brand voice, nuanced messaging Opus Requires judgment, taste, and editorial thinking

When in doubt, default to Sonnet. It handles 80% of tasks well. Switch up or down based on results.
