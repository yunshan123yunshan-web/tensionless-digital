Exercise: Draft a Skill

You'll create a complete skill from scratch. Pick one of the scenarios below.

Scenario A: Bug Report Skill

Create a skill that takes a bug description and produces a structured report: steps to reproduce, expected vs actual behavior, environment details, severity assessment, and suggested next steps.

Scenario B: Content Brief Skill

Create a skill that generates a content brief from a topic idea: target audience, key message, structure outline, tone guidelines, SEO keywords, and call to action.

Scenario C: Your Own Idea

Pick a task you do at least weekly. Draft a skill for it. Remember: specific scope, clear inputs, structured output.

Deliverable: A complete SKILL.md file with name, description, and step-by-step instructions. Bonus: create the folder structure and ask Claude to test the skill.
