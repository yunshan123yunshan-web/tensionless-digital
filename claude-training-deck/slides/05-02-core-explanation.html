Three Different Surfaces

Claude Code offers three modes. Picking the right one is like picking the right tool for a job.

Chat

Conversational Q&A. Ask questions, get answers, iterate on ideas. No file system access — pure dialogue.

Best for: exploration, learning, drafting, quick answers

Dialogue

Cowork

Full file-system access. Read, write, edit, run commands. Claude works alongside you in your project directory.

Best for: coding, editing, file operations, complex tasks

Collaboration

Skills

Reusable, packaged workflows. Turn a well-prompted task into a /command that anyone can run.

Best for: repeatable processes, team workflows, automation

Automation

The three modes are complementary, not competing. A typical workflow: Chat → explore ideas, Cowork → implement them, Skill → package for reuse.
