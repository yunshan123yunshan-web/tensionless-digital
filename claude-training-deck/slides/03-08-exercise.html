Exercise: Pick the Model

For each task, decide: Haiku, Sonnet, or Opus?

Tasks

Sort a 10,000-row CSV by date → Haiku
Design a microservices architecture for a new platform → Opus
Refactor a React component for better performance → Sonnet
Draft a weekly status update email → Haiku
Analyze a complex legal contract for risks → Opus
Generate 50 product descriptions from a spec sheet → Sonnet

Discuss: Were any of these ambiguous? What would make the choice clearer?
