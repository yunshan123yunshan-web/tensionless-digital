The Five Context Files

Build these files once. Reference them forever. Each solves a specific problem.

FileWhat it containsWhen to reference
about-me.md Your role, responsibilities, goals, preferences, experience level Every conversation — sets the baseline
my-company.md Company overview, positioning, competitors, audience, metrics Client work, strategy, any external-facing output
writing-style.md Tone, vocabulary, formatting rules, pet peeves, examples Any writing task — email, doc, proposal, social
anti-ai.md What you don't want Claude to do — clichés, overused phrases, bad patterns Review tasks, before generating final output
decision-rules.md Trade-off preferences, priorities, principles for judgment calls Architecture, strategy, any decision with options

Pattern: Claude doesn't read context files automatically — you reference them in prompts: "Read my writing-style.md before drafting this email."
