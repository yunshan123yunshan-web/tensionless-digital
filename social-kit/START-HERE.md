# Tensionless Digital — social starter kit

Created 24 November 2026. Nothing has been published to either platform.

## Upload these first

1. **Both profile photos:** upload `upload/01-profile-ig-facebook.png`. Keep the mark centred in the circular crop. The light file is an optional alternative; use the same choice on both platforms.
2. **Facebook Page cover:** upload `upload/02-facebook-cover.png`. Keep it centred. Check the actual desktop and mobile previews before saving; the local previews are crop simulations rather than live platform screenshots. The cover is intended for Facebook; the square profile image works on both pages.
3. **First post on both pages:** `upload/03-post-introduction.png`, with caption 1 in `POST-CAPTIONS.md`. Pin it if that option is available.
4. **Next posts:** publish the services graphic, then the landing-page check, each with its matching caption. Use the full 4:5 image when posting. These are three independent posts and do not need to form one continuous profile-grid image.

Upload files are in `upload/`. `POST-CAPTIONS.md` includes captions and suggested alt text. `previews/` contains a visual overview, cover crop simulations and the render check report. Editable artwork, the supplied original logo, derived transparent logo assets and bundled project fonts are in `source/`.

The black, off-white and steel palette and the real logo come from the existing project. No stock photos, AI-generated photos, invented clients, results or testimonials were used. The mark-only profile image preserves the supplied logo's geometry and improves its readability at small sizes.

For the editable designs, open `source/artboards.html` in a browser. The default is the introduction post; append `?asset=profile-dark`, `?asset=profile-light`, `?asset=facebook-cover`, `?asset=post-services` or `?asset=post-checklist` to view another artboard. Fonts and logo assets are bundled; no network requests are required.

The project-level `SOCIAL-PROFILES.md` remains the canonical profile and post copy record. This kit contains an export for convenient uploading.
