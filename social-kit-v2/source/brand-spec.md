# Tensionless Digital — revised social art direction

Created 24 November 2026. V2 responds to the first set being too restrained and text-heavy. The existing logo, brand colours and service scope are retained; the change is a stronger imagery-led campaign.

## Image generation provenance

- Provider: the owner's configured chr1 relay, used with their explicit authorisation.
- API path: OpenAI-compatible Images API through the installed imagegen skill CLI.
- Model: gpt-image-2; high quality; four distinct generated conceptual images.
- Exact prompt set: prompts.jsonl. No credential values are saved in this package.
- Generated backgrounds: generated/hero-wide.png, generated/intro.png, generated/services.png, generated/checklist.png.
- The imagery is conceptual CGI. It is not evidence of client work, a real campaign dashboard, a real office or a team photo.
- Logo and type are composited locally so their identity and spelling remain exact. The original brand mark has not been regenerated by AI.

## Design system

- Black #050507, off-white #f0f2f4, light text #e9edf2 and steel #b8c4d0 from the existing project; restrained blue #8fb0ff is already used in the website's chrome lighting.
- Existing local Inter and Cormorant Garamond fonts; no external font calls.
- Editorial type with a short headline, large purposeful artwork and a small brand signature. Supporting explanation stays in captions.
- Core visual idea: separate marketing channels resolve into one connected customer journey.
- Cover: a chrome ribbon resolves from a loose knot into a clean path, alongside the brand line Marketing, without the tension.
- Introduction: separate chrome strips unite into one direction.
- Services: three physical portals share one continuous path.
- Educational post: an optical loupe inspects the point where paths align.

## Output and review

Profile images 1080×1080; Facebook cover 1640×720; three independent feed posts 1080×1350. These are practical production canvases rather than assertions about an exact platform-required size. Check the actual Facebook cover upload preview before saving. Local preview crops are simulations.

The profile mark remains centred within a circular crop. Headlines, brand signatures, generated-image edges and cover crop safety are checked before packaging. No campaign statistics, client names or testimonial claims are added.
